# Security Policy

Race Control handles activity data from developers' AI agents, so security reports are taken seriously.

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Report it privately through [GitHub's security advisory form](https://github.com/sithija-jayasinghe/race-control/security/advisories/new), or email **harshanajayasinghe113@gmail.com** with:

- What the issue is and where it is
- Steps to reproduce it
- The impact you think it has

You'll get a reply within 5 days. Once it's fixed, you'll be credited in the release notes if you'd like.

## Supported versions

Race Control is pre-release. Security fixes go into the `main` branch.
